BOUNCE BACK 🎮
A 2D adventure game developed using Godot.
About
Bounce Back is an adventure game where players explore different levels, collect items, overcome obstacles, and reach their goals.
Built With
- Godot Engine
- GDScript
How to Play
1. Download the game.
2. Extract the ZIP file.
3. Run the game executable.

This project is open to contributions, suggestions, and improvements.
